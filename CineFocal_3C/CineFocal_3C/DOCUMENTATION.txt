 1. QUICK OVERVIEW & FEATURES / 1. نظرة عامة ومميزات القالب
--------------------------------------------------------------------------------
[EN]:
- Data-Driven Architecture: Update your entire site from a single configuration file (`js/config.js`) without touching HTML.
- 3D Aperture Intro Lens: Realistic mechanical camera lens that opens with smooth physics.
- 3D Floating Gallery: Smooth inertia drag-and-drop 3D portfolio cards with auto-floating animation.
- Animated Line-Art Sketch Background: Futuristic cyberpunk photography sketch background with subtle parallax response.
- Integrated Booking System: Direct modal with one-click WhatsApp and Email pre-filled booking messages.
- Full Bilingual Support: Instant switching between Arabic (RTL) and English (LTR).
- Dark & Light Mode: Seamless cyberpunk dark theme and modern crisp light theme.

[AR]:
- بنية برمجية موجهة بالبيانات (Data-Driven): يمكنك تعديل كامل محتوى الموقع من ملف واحد (`js/config.js`) دون الحاجة لفتح أو كتابة كود HTML.
- عدسة كاميرا 3D تفاعلية: محاكاة ميكانيكية واقعية لفتحة العدسة وانفتاح الشفرات عند فتح الموقع.
- معرض أعمال ثلاثي الأبعاد: بطاقات 3D تفاعلية تدعم السحب الفيزيائي، الطفو التلقائي، والتكبير المباشر.
- نظام رسومات سكتش متحرك: خلفية فنية مستوحاة من معدات التصوير والسينما تتحرك بنعومة مع مؤشر الفأرة (Parallax).
- نظام حجز وطلب خدمات فوري: نافذة منبثقة تنشئ رسائل حجز تلقائية ومخصصة باسم الخدمة وسعرها للواتساب والبريد.
- دعم كامل للغتين: تبديل فوري بين العربية (RTL) والإنجليزية (LTR) مع مراعاة اتصال الخط العربي.
- وضع ليلي ونهاري: تبديل سلس بين الثيم السيبراني الداكن والثيم النهاري الأنيق.

 2. HOW TO RUN THE WEBSITE LOCALLY / 2. طريقة تشغيل الموقع على جهازك
--------------------------------------------------------------------------------
[EN]:
1. Extract the downloaded `.zip` folder to your computer.
2. Locate the `index.html` file inside the root folder.
3. Double-click `index.html` to open it in any web browser (Chrome, Safari, Edge, Firefox).
4. No Node.js, Apache, PHP, or local server installation is required.

[AR]:
1. فك الضغط عن المجلد الذي قمت بتحميله (`.zip`).
2. ادخل إلى المجلد وافتح ملف `index.html`.
3. انقر نقراً مزدوجاً على الملف ليفتح مباشرة في متصفحك المفضل (كروم، سفاري، إيدج، فايرفوكس).
4. لا يتطلب تشغيل الموقع أي برامج خوادم إضافية مثل (Node.js أو XAMPP أو PHP).

 5. 2-MINUTE CUSTOMIZATION (config.js) / 5. التخصيص السريع
--------------------------------------------------------------------------------
[EN]:
Open `js/config.js` in your favorite code editor or Notepad. You will find clearly commented sections:

1. Brand & Personal Name:
   - `nameEn`: Modify letters in the array -> `["J", "O", "H", "N", " ", "D", "O", "E"]`
   - `nameAr`: Modify words in the array -> `["المصور", "محمد", "علي"]`
   - `metaTitle`: Update browser tab title text.

2. HUD Personal Information:
   - Edit, add, or delete items inside `personalInfo: [ ... ]`. The grid automatically adapts.

3. Skills & Progress Bars:
   - Edit, add, or delete skills inside `skills: [ ... ]`. Set `percentage: 95` (from 0 to 100).

4. Services & Pricing Packages:
   - Edit, add, or delete packages inside `services: [ ... ]`.
   - Update `titleAr`, `titleEn`, `price`, and `currency`. The site auto-generates booking buttons.

5. Contact & Social Channels:
   - `phoneRaw`: Your WhatsApp/Call number with country code, NO symbols (e.g., "12025550199").
   - `phoneDisplay`: Formatted number for display (e.g., "+1 (202) 555-0199").
   - `email`: Your direct email address for receiving bookings.
   - `socials`: URLs for your Instagram, TikTok, Facebook, and WhatsApp profiles.

[AR]:
افتح الملف `js/config.js` بمحرر النصوص وستجد كل قسم معنون ومفصل بوضوح:

1. الاسم والهوية الشخصية (Brand):
   - الاسم بالإنجليزي (`nameEn`): ضع أحرف اسمك مفصولة بين علامات تنصيص لضمان الحركة التفاعلية.
   - الاسم بالعربي (`nameAr`): ضع كلمات اسمك كاملة لضمان اتصال الخط العربي الأصيل.
   - عنوان التبويب (`metaTitle`): العنوان الذي يظهر أعلى نافذة المتصفح.

2. بيانات لوحة الـ HUD الشخصية (personalInfo):
   - يمكنك تعديل المهنة، العمر، الموقع، أو إضافة بنود جديدة مثل سنوات الخبرة ونوع الكاميرا المستخدمة.

3. المهارات وأشرطة التقدم (skills):
   - أضف مهاراتك وحدد النسبة المئوية من 0 إلى 100 عبر السطر `percentage: 90`.

4. باقات الخدمات والأسعار (services):
   - أضف أي عدد من باقات التصوير، وضع السعر والوصف، وستتمدد شبكة الخدمات وتتصل بنظام الحجز تلقائياً.

5. قنوات التواصل والحجز (contact):
   - رقم الهاتف المباشر (`phoneRaw`): اكتب رقمك مع الرمز الدولي وبدون مسافات لتشغيل الواتساب والاتصال.
   - البريد الإلكتروني (`email`): بريدك المخصص لاستقبال تفاصيل الحجوزات.
   - روابط منصات التواصل (`socials`): روابط حساباتك في انستقرام، تيك توك، وفيسبوك.

[EN]:
Changing Accent Colors via CSS:
- Open `css/style.css`
- Dark Mode Accent (Line 24): `--hud-accent: #F3E600;` (Change to your desired neon hex code).
- Light Mode Accent (Line 38): `--hud-accent: #2563eb;` (Change to your desired color).

- اللون في الوضع النهاري (السطر 38): غير القيمة `--hud-accent: #2563eb;` للون المفضل لديك.

 7. DEPLOYMENT & HOSTING OPTIONS / 7. طرق رفع واستضافة الموقع
--------------------------------------------------------------------------------
[EN]:
Option A: Free Cloud Hosting (Fastest & Easiest)
- Netlify: Go to `app.netlify.com/drop`, drag and drop the `CineFocal-3D` folder. Your site is live in 10 seconds!
- Vercel: Connect your GitHub repository to Vercel for automatic deployment.
- GitHub Pages: Push files to a repository and enable GitHub Pages under Settings > Pages.

Option B: Traditional Shared Hosting (cPanel)
1. Compress all project files into a `.zip` archive.
2. Log into your cPanel and open File Manager.
3. Upload the `.zip` into the `public_html` directory.
4. Extract the `.zip` archive. Your website is now live on your domain.

[AR]:
الخيار الأول: استضافات سحابية مجانية فائقة السرعة (الأسهل والأسرع)
- Netlify: افتح الرابط `app.netlify.com/drop` واسحب مجلد المشروع كاملاً وأفلته هناك. موقعك سيعمل خلال 10 ثوانٍ!
- Vercel: ارفع مشروعك على منصة GitHub واربطه بـ Vercel ليتم نشره تلقائياً.
- GitHub Pages: ارفع ملفاتك على مستودع GitHub وفعل خيار Pages من تبويب الإعدادات.

الخيار الثاني: استضافات الـ cPanel التقليدية المدفوعة
1. اضغط ملفات المشروع في ملف واحد بصيغة `.zip`.
2. ادخل إلى لوحة التحكم cPanel ثم افتح إدارة الملفات (File Manager).
3. ارفع الملف المضغوط داخل المجلد الرئيسي `public_html`.
4. فك الضغط عن الملف، وسيعمل موقعك مباشرة على نطاقك الخاص (Domain).
